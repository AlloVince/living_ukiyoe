# 生きている浮世絵（Living Ukiyo-e）

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

![動き出す大波](media/living-ukiyoe.gif)

葛飾北斎の《神奈川沖浪裏》に、静かな動きを与えました。波、雲、しぶきのリズムを調整し、リンクで自分のシーンを共有できます。すべてブラウザー内で動作し、アカウントもサーバーも必要ありません。上の GIF は折りたたまれた紙面から始まり、各レイヤーが順に現れる導入を経て、安定した 28 秒ループに入ります。初回アクセス時に再生される流れそのものです。

[ライブデモ · Cloveread Radio](https://cloveread.com/radio/) · **Wave Lab：**ローカルで実行できる独立した実験環境です。

## 波の5つの段階

![プロシージャルな波から完成した版画まで](media/ukiyoe-evolution.gif)

Wave Lab では、制作の全過程を5つのバージョンとして切り替えて見ることができます（パネル上部のドロップダウンから選択）。各バージョンは実際の制作時点の状態を忠実に復元したもので、後から描き直したものではありません。

1. **V1 · プロシージャルな3Dの波** — 最初の Radio テーマ（コミット 1ee33a5）：変位メッシュで生成した大波と GPU によるしぶき。版画のテクスチャは使わず、決定論的な環境スペクトルのフォールバックを備えています。
2. **V2 · 移動する波頭**（コミット 7ad5464）：波頭が生成 → 隆起 → 崩れ → 収束の過程をたどり、泡、しぶき、ハイライトも同じ波頭に連動します。全体の動きはマクロモーション・ディレクターが制御します。
3. **V3 · 手描きの2Dの波**（コミット a2973be）：5層の平面2Dの海に、Canvas で描いた手描きの主波を組み合わせたもの。アート方向の確認段階では静止状態にしていました。
4. **V4 · 版画＋実験レイヤー** — 凍結した Wave Lab を Radio に移植した時点の状態（d1f38f6）：元の版画レイヤーに、海面の下地、遠景・中景・近景の穏やかな波、原画の飛沫、落款などの実験レイヤーを重ね、それぞれ個別に表示・非表示を切り替えられます。
5. **V5 · 最終作品** — 現在の Radio の浮世絵テーマです。確認済みのレイヤー構成だけを残し、版画本来の題箋、署名、印章を復元しました（2026-11-10 の Owner 判断によるもの）。絵の具箱を思わせるフレーミング、温かみのある紙、再生開始後に動き出す28秒ループ、紙が開く演出と連動したレイヤーごとの登場を備えています。

V1〜V4 は制作過程を示す歴史的な展示です。再生、停止、リプレイ、録画はできますが、完成作品として扱ってはいません。V5 ではすべての制作コントロールを利用できます。各バージョンの状態は独立しており、共有リンクにはバージョン情報が含まれます。バージョン導入前の古いリンクは、当時の状態である V4 を正確に復元します。

## ローカルで実行する

Node.js 24 と pnpm 11.1.2 が必要です。このディレクトリで実行してください。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`http://127.0.0.1:4177/` を開きます。ソースを変更すると自動で再ビルドされるので、ページを更新してください。このディレクトリは独立したワークスペースで、依存関係とロックファイルもここで管理します。

```sh
pnpm build
pnpm check
pnpm test
pnpm exec playwright install chromium
pnpm e2e
```

E2E テストは実際の `/living_ukiyoe/` パスで実行されます。[エンジニアリングノート](ENGINEERING.md)では、手動でのパス確認、GPU 計測、README 用アニメーションの再生成方法を説明しています。

## 調整できるもの

- 各レイヤー、個々の波、3隻の船、富士山、落款。
- 波の速度、前進量、うねり、レイヤーごとのタイミング。
- 青い墨の模様、6つの雲領域、海しぶき、構図、再生状態。

パネル端のフローティングボタンでパネルをそのボタンだけの状態まで畳めます（もう一度押すと戻ります）。スマートフォンではパネルが作品の下に配置されます。言語はブラウザーの設定に従い、English・中文・日本語を切り替えられます。共有メニューには X・Weibo・Facebook・Telegram・メールとリンクのコピーが並び、対応ブラウザーでは OS の共有シートも使えます。[バージョン付きフラグメント](SHARING.md)から作品の状態を復元できます。動きを抑える設定にも対応し、完全な静止画も用意しています。

## 仕組み

Three.js が登録済みの透明な顔料レイヤーを共通座標系でアニメーションさせ、決定論的な28秒ループを実現しています。承認済みのシーンとテクスチャは[ビジュアルベースライン](evidence/baseline/manifest.json)で保護されています。公開 UI は元のレンダラーをそのまま呼び出します。Cloveread のランタイム、作品 API、オンライン AI には依存しません。
